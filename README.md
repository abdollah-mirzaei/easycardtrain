# 🎴 EasyCardTrain — دستیار هوشمند مرور

یک پلتفرم Local-First برای مدیریت یادگیری و مرور دروس بر پایه **Spaced Repetition** (مرور فاصله‌دار)، **Active Recall** (بازیابی فعال) و **Adaptive Learning** (یادگیری تطبیقی).

## ✨ ویژگی‌ها

- 📚 **مدیریت دروس و مباحث**: ساختار سلسله‌مراتبی درس، فصل و مبحث
- 🎴 **فلش‌کارت هوشمند**: ایجاد و مدیریت فلش‌کارت با اتصال به درس‌ها
- 🧠 **الگوریتم لایتنر**: مرور فاصله‌دار با ۵ جعبه و ارزیابی چهارسطحی
- 📊 **داشبورد و گزارش‌ها**: مشاهده پیشرفت، آمار و نقاط ضعف
- 📱 **PWA و Offline First**: نصب‌پذیر و قابل استفاده بدون اینترنت
- 🌐 **فارسی و RTL**: رابط کاربری کاملاً فارسی و راست‌چین
- 💾 **Local First**: تمام داده‌ها در مرورگر شما ذخیره می‌شوند (بدون نیاز به سرور)
